## 🚀 Deployment Options

### Option 1: Docker Compose (Recommended for Development)
```bash
docker-compose up -d
```
Access at: http://localhost:3000

### Option 2: Docker Build (Production)
```bash
docker build -t api-lifecycle-portal:latest .
docker run -p 80:80 api-lifecycle-portal:latest
```

### Option 3: GitHub Container Registry (CI/CD)
Automatically builds and pushes on push to main branch

## 🔧 Configuration

### API URL Priority (Automatic)
1. REACT_APP_API_URL environment variable
2. Production mode → /api (relative)
3. Development mode → http://localhost:8000

### For Different Environments

**Local Development:**
- Uses http://localhost:8000
- No configuration needed

**Docker:**
- Uses /api (nginx proxy)
- Configured in docker-compose.yml

**Production:**
- Uses /api (relative path)
- Set in build: REACT_APP_API_URL=/api

**Custom API:**
- Set REACT_APP_API_URL=https://your-api.com
- Works in all environments
